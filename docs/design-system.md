# AB-Dels Signature: Design System

## Brand feeling
Premium, elegant, trustworthy. Spacious and uncluttered. Mobile first.

## Colours
| Token | Value | Use |
|---|---|---|
| gold | #C9A66B | Accents, buttons, thin lines, headings on black |
| black | #111111 | Main text, dark sections |
| ivory | #F7F3E8 | Page backgrounds |

Rules:
- Gold on black: allowed for headings, icons and lines.
- Gold on ivory: decoration only (lines, borders). Never for text.
- Buttons: gold fill with black text. Never white text on gold.
- Body text on ivory: black.

## Typography
- Headings: Cormorant Garamond, weight 600
- Body: DM Sans, weights 400 and 500
- Body size: 16px minimum, line height 1.6
- Heading line height: 1.2
- Sizes (mobile / desktop): h1 40/56px, h2 28/36px, h3 20/24px, small 14px

## Spacing
Base unit 8px. Scale: 4, 8, 16, 24, 32, 48, 64.
Generous white space between sections (48 to 64px).

## Components
- Corner radius: 4px (subtle)
- Primary button: gold fill, black text, minimum height 44px
- Secondary button: transparent, 1px gold border
- Visible focus outline on every interactive element

## Layout
- Mobile first. Breakpoints: 600px, 900px, 1200px
- Max content width 1200px, centred

## Images
- Real product photos, consistent lighting and background
- Compressed (WebP where possible), alt text on every image

## Accessibility
- Text contrast at least 4.5 : 1
- Touch targets at least 44px
- Never rely on colour alone to show meaning

## Pages (MVP)
Home, Shop, Product details, How to order, Bulk and custom quote,
Delivery info, About, Policies, Contact.

## Menu and footer
- Menu: Home, Shop, How to order, Request a quote, About, Contact
- Footer: How to order, Delivery, Policies, About, Contact, social links
- WhatsApp: floating button on every page, plus a homepage section
